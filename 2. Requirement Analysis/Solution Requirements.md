# Solution Requirements

| Field | Details |
|---|---|
| Team ID | SWTID-2026-8639 |

## Functional Requirements

| FR No. | Functional Requirement | Sub Requirement |
|---|---|---|
| FR-1 | Document Upload | Upload PDF, DOCX or paste text |
| FR-2 | Text Extraction | Extract and clean text from the uploaded document |
| FR-3 | Simplification | Generate a plain-language summary of the document |
| FR-4 | Risk Detection | Highlight risky or unusual clauses with a short reason |
| FR-5 | Question and Answer | Answer user questions using only the uploaded document |
| FR-6 | Glossary | Explain legal terms found in the document |
| FR-7 | Disclaimer | Show that output is guidance and not legal advice |

## Non-Functional Requirements

| NFR No. | Non-Functional Requirement | Description |
|---|---|---|
| NFR-1 | Usability | Simple screens usable by non-technical users |
| NFR-2 | Security | Uploaded documents are kept private and not shared |
| NFR-3 | Reliability | Answers stay faithful to the document content |
| NFR-4 | Performance | Summary generated within 10 seconds for a typical document |
| NFR-5 | Availability | Works reliably during normal use |
| NFR-6 | Scalability | Can handle more users and longer documents with cloud deployment |
