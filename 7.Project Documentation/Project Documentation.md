| How to Use | Upload a document, read the summary, review flagged clauses, check the glossary and ask questions in chat |
| Limitations | Output is general guidance and not legal advice; users should consult a lawyer for serious decisions |
| Future Scope | Regional language support, more document types and lawyer connect option |
